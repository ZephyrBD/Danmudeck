# DanmuDeck 使用教程

DanmuDeck 由两部分组成：**管理台**（你在浏览器里操作的页面）和**覆盖页**（放进直播姬或 OBS 的画面源）。直播姬/OBS 负责采集画面，DanmuDeck 负责把弹幕、SC 和排队信息渲染成透明的网页图层。

## 一、登录

1. 打开 `http://localhost:3000/manage`，页面中央会出现二维码。
2. 用手机 B 站 App 扫一扫，确认登录。
3. 登录成功后自动进入三列管理台。

> 二维码过期时点「重新生成二维码」即可。退出登录按钮在顶栏最右侧，退出后会自动刷新出新的二维码。

## 二、直播姬教程

### 1. 添加浏览器源

1. 打开直播姬 → **添加素材** → 选择 **浏览器**。
2. 复制下面的地址填进「网页地址」：

```
{chat_url}
```

3. 分辨率建议填 `1920 × 1080`，勾选「本地文件」以外的透明选项，背景色保持默认透明。
4. 把这个浏览器源拖动到底层作为背景，弹幕会被自动叠在画面右下角。

### 2. 排队覆盖

观众在直播间发送「排队」即可入队。若想单独显示排队列表，再加一个浏览器源：

```
{queue_url}
```

### 3. 常见问题

- **画面一片空白**：确认 DanmuDeck 服务正在运行（浏览器能打开 `{chat_url}`）。
- **弹幕不刷新**：检查管理台右上角的连接状态点是否为绿色。
- **想换位置**：直播姬里直接拖动浏览器源，或者修改覆盖页设置里的显示条数。

## 三、OBS 教程

{obs}

### 推荐设置

| 选项 | 值 |
| --- | --- |
| 宽度 | 1920 |
| 高度 | 1080 |
| FPS | 30 |
| 自定义 CSS | 留空（覆盖页自带样式） |
| 关闭源时关闭页面 | 否 |

### 三种排队形态

| 形态 | 说明 |
| --- | --- |
| 列表（竖排） | 逐条竖排显示，超出显示条数时截断 |
| 横向 | 从左到右排布，超出时换行 |
| 流动 | 超出显示条数时自动下翻，底部停留后再翻回顶部 |

流动形态可以在「覆盖」页签里调节 **流动速度（秒/屏）** 与 **底部停留（秒）**。

## 四、排队与礼物插队

1. 最右侧的队列列会实时显示所有人，行首是名次，名字右边会标出「礼物插队」或「已完成」。
2. 每一行右侧有两个图标按钮：**置顶**（↑，插队到第 1 位）和 **完成**（✓，标记为已完成）。也可以直接拖拽行调整顺序。
3. 队列栏右上角的四个图标依次是 **保存 JSON / 加载 JSON / 清除已完成 / 清空**。
4. 「规则」页签里配置礼物插队：观众送出指定礼物累计到阈值后自动置顶或前进若干位。

## 五、帮助与反馈

遇到问题先看管理台顶栏的连接状态与日志。服务端日志会打印每一次登录、队列和覆盖设置变更。
